# 欢迎来到我的博客

这是你的第一篇博客文章。博客内容以 Markdown 文件形式存储在 `posts/` 目录中。

## 功能特性

- **Markdown 支持**：使用 Markdown 语法编写文章
- **静态生成**：构建时自动生成页面，加载速度极快
- **响应式设计**：在手机和电脑上都能完美显示
- **深色模式**：支持深色/浅色主题切换
- **Vercel 部署**：一键部署，自动 HTTPS

## 如何写新文章

1. 在 `posts/` 目录下创建 `.md` 文件
2. 文件头部添加 YAML frontmatter（如上所示）
3. 使用 Markdown 编写正文内容
4. 推送到 GitHub，Vercel 自动重新部署
